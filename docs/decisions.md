# ข้อกำหนดและสถานะข้อมูล

## ลำดับความสำคัญ

1. บทเรียนสำคัญที่สุด ผู้เรียนระบุว่าการลงทะเบียนน่าจะไม่มีปัญหาแล้ว
2. ใช้ 7 วิชาที่ลงจริงตามภาพ 10 ต.ค. 2569 เป็นเทอมแรก รวม 21 นก.
3. เรียนพื้นฐานก่อนแนวคิดต่อยอด สลับวิชาที่ประเมินว่าหนักกับเบากว่า
4. ต้องการจบเร็วภายในกรอบ 2–3 ปี โดยให้ได้วุฒิก่อน เป้าหมายสอบปลัดเดิมเก็บเป็นบริบท ไม่บังคับติวในเส้นทางหลัก
5. ปริญญาตรีใบที่สอง ใช้สิทธิเทียบโอนจากสถาบันอื่น; ฐานแผน C ส่วนกลาง

6. เรียนไปด้วยทำงานไปด้วย มีเวลาเรียนวันละ 2–4 ชั่วโมง ต้องการเนื้อหาที่เข้าใจง่ายและหน้าตาน่าเรียน (11 ต.ค. 2569)

## สิ่งที่ยืนยันจากข้อมูลผู้เรียน

- POL1101, POL2104, POL2106, POL2107, POL2200, POL2301, POL2303 ลงแล้วในภาค 2/2569
- วันสอบและคาบใส่ตรงภาพ ไม่มีชั่วโมงสอบในข้อมูลที่ใช้ จึงใช้กิจกรรมปฏิทินทั้งวัน
- ไม่แทนรายวิชาจริงด้วยรายการในแผน Excel เก่า ซึ่งยังมี POL2300 / POL2108 ในเทอมแรก
- ภาพตัวอย่างผู้เรียนคนอื่นใช้เป็นแนวทางเท่านั้น ไม่คัดลอกเกรด ชื่อ หรือรหัสนักศึกษา
- 11 ต.ค. 2569 ผู้เรียนส่งภาพหน้าลงทะเบียน (iregis2s1.ru.ac.th) อีกครั้ง ตรวจแล้วรหัส หน่วยกิต วันสอบ และคาบตรงกับข้อมูลในแอปทั้ง 7 วิชา

## สมมติฐานที่แสดงแยก

- หลักสูตร 126 นก. คาดเทียบโอน 42 นก. (ศึกษาทั่วไป 30 + เลือกเสรี 12) แต่เริ่มสถานะอนุมัติที่ 0
- แผน 84 นก.: 18 แกน + 24 เอกบังคับ + 24 เอกเลือก + 18 เลือกในคณะ
- 6 ภาค: 21, 9, 18, 18, 9, 9 นก. และภาคสำรอง เป้าหมายสอบครบ 1/2571 ไม่ใช่วันอนุมัติจบที่รับรอง
- ภาคอนาคตทั้งหมดต้องตรวจวิชาเปิด มร.30 เงื่อนไขผู้สอน และเพดานตามสิทธิจริง
- ไม่มีข้ออ้างว่าแผน C ง่ายกว่า A หรือทำให้จบเร็วกว่าจากหลักฐานเชิงสถิติ
- ไม่มีการเดาว่าประกาศแผนต้องทำปี 2 หรือเมื่อจบ เพราะยังไม่มีหลักฐานทางการที่ชัดเจน
- ไม่ยืนยันรูปแบบข้อสอบภาคปัจจุบันจากภาพสีหรือคำบอกเล่าภาคเก่า
- ไม่คาดเดารอบเปิดสอบปลัดจากระยะห่างในอดีต

## การปรับรุ่น 11 ต.ค. 2569

- ตรวจเนื้อหา 35 บทแล้วไม่พบข้อเท็จจริงที่ผิด แต่ภาษาเป็นวิชาการและขาดชื่อแนวคิดที่ตำรามักใช้ จึงเพิ่ม “เข้าใจใน 1 นาที” แยกไฟล์ `easy.js` โดยไม่แก้เนื้อหาเดิม
- ชื่อ/คำในส่วน terms เป็นความรู้พื้นฐานทางรัฐศาสตร์และการบริหารที่เผยแพร่ทั่วไป ไม่ได้อ้างว่าตรงกับตำราของอาจารย์ภาคนี้
- แผนรายวัน: ค่าเริ่มต้นวันทำงาน 2 ชม. วันหยุด 4 ชม. มีโหมด 1 ชม. สำหรับวันยุ่ง ช่วงเวลาภายในวันคงที่เพื่อให้คาดเดาได้ (การ์ด → วิชาหลัก → วิชารอง → คำบรรยาย → วิชาที่ตามไม่ทัน → ปิดท้าย)
- ช่วงทบทวนเริ่ม 1 ก.พ. 2570 เป็นการแบ่งเวลาที่แนะนำ ไม่ใช่วันจากปฏิทินมหาวิทยาลัย
- แฟลชการ์ดของบทเข้าคิวหลังกดอ่านจบ เพื่อไม่ให้มีการ์ดค้างหลายร้อยใบในวันแรก
- หน้าตา: คงพื้นสว่างโทนน้ำเงินและหัวตารางน้ำเงินเข้มตามข้อกำหนดเดิม เพิ่มสีประจำวิชา การ์ดมุมโค้ง แถบเมนูล่างบนมือถือ และฟอนต์ Noto Sans Thai / Prompt จาก Google Fonts (ถ้าโหลดไม่ได้จะใช้ฟอนต์ไทยของเครื่อง)

## การตัดสินใจทางเทคนิค

- อ่านง่ายเป็นหลัก: พื้นสว่าง โทนน้ำเงิน ตัวอักษรหลักเข้ม ข้อความรองยังต้องเห็นชัด หัวตารางน้ำเงินเข้มตัวอักษรขาว เส้นตารางและกรอบช่องชัด พร้อมแถวสลับสี หลีกเลี่ยงข้อความเทาอ่อนและตัวหนังสือเล็กในมือถือ ตามข้อแก้ไขของผู้เรียน 10 ต.ค. 2569

- Static HTML/CSS/JavaScript เพื่อลดการติดตั้ง เปิดบนมือถือได้ ไม่มี account ใหม่หรือค่าบริการ API
- บทเรียนเขียนใหม่ มีขอบเขตพื้นฐานชัดเจน ไม่วางข้อความ placeholder แทนเนื้อหา
- ข้อมูลส่วนตัวที่ไม่จำเป็น เช่น นายจ้าง อีเมล รหัสนักศึกษา และภาพที่มีข้อมูลบุคคล ไม่ฝังใน source
- ข้อมูลผู้เรียนเก็บในเบราว์เซอร์ พร้อมส่งออก JSON / Markdown / CSV / ICS
- เนื้อหาใหม่และแก้ไขข้อมูลหลักสูตรทำผ่านไฟล์ข้อมูลที่แยกจากส่วนแสดงผล

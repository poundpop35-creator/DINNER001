# RU Study Planner

ห้องเรียนรัฐศาสตร์ภาษาไทยส่วนตัว เน้น **บทเรียนของ 7 วิชาที่ลงจริงในภาค 2/2569**

**เปิดแอป:** [RU Study Planner บน GitHub Pages](https://poundpop35-creator.github.io/RU-Study-Planner/)

โปรเจกต์ [RU-Study-Planner](https://github.com/poundpop35-creator/RU-Study-Planner) เปลี่ยนเป็นแอปเรียนรัฐศาสตร์แล้ว อ่านและจดในเครื่องได้ทันที เข้าสู่ระบบเพื่อซิงก์ข้อมูลส่วนตัวผ่าน Supabase ข้อมูลในเครื่องแยกตาม origin และบัญชี หากย้ายจากเว็บตัวอย่าง ให้ส่งออก JSON จากหน้า “ตั้งค่าและสำรองข้อมูล” แล้วนำเข้าในเว็บนี้

## สิ่งที่ใช้ได้

- บทเรียนพื้นฐานเรียบเรียงใหม่ **35 บท** (5 บทต่อวิชา) พร้อมแนวคิด 3 ส่วน กรณีวิเคราะห์ จุดสับสน และศัพท์ทบทวน
- **เข้าใจใน 1 นาที** ทุกบท: สรุปหนึ่งประโยค 3 ประเด็นหลัก ตัวอย่างเปรียบเทียบจากชีวิตประจำวัน วิธีจำ และชื่อ/คำที่ตำรามักใช้ (เช่น Leviathan, POSDCORB, Hawthorne, Kirkpatrick)
- **แนวข้อสอบ 7 วิชา**: รูปแบบข้อสอบ ตำรา หัวข้อที่ควรเตรียม สิ่งที่ข้อสอบเก่าเคยถาม ลิงก์ข้อสอบเก่าจริง และข้อสอบเสมือน **173 ข้อ** แบบ 5 ตัวเลือก (โหมดฝึกทีละข้อ / จำลองสอบ เก็บคะแนนดีสุด)
- **แผนวันนี้** สำหรับคนทำงาน มีเวลาวันละ 1–4 ชั่วโมง เลือกได้รายวัน (ค่าเริ่มต้น วันทำงาน 2 / วันหยุด 4) แบ่งเป็นช่วงสั้นที่ติ๊กได้ นับถอยหลังวันสอบ และนับวันเรียนต่อเนื่อง
- แผนเปลี่ยนตาม 4 ช่วง: เรียนเนื้อหา (ถึง 31 ม.ค. 2570) → ทบทวนตามลำดับวันสอบ → ช่วงสอบ (โฟกัสวิชาถัดไป) → สอบครบ
- คำถามแต่งใหม่ **70 ข้อ** พร้อมคำอธิบายคำตอบและตัวกรองข้อที่ตอบผิด
- แฟลชการ์ด **201 ใบ** นัดทบทวน 1 / 3 / 7 วัน การ์ดของบทเข้าคิวหลังกดอ่านจบ (เลือกรวมทุกบทได้)
- สมุดจดแบบจัดรูปแบบ: ตัวหนา/เอียง/ขีดเส้นใต้ รายการ หัวข้อ ไฮไลต์ 5 สี ตัวอักษร 6 สี รูปภาพ และ undo/redo
- โน้ตหลายหน้า แยกวิชา/บทเรียน แท็ก ค้นหา ปักหมุด เก็บคลัง และคำถาม–คำตอบสำหรับทวนจากโน้ต
- รูป JPG/PNG/WebP/GIF ไม่เกิน 5 MB/รูป เก็บใน IndexedDB และซิงก์ private Storage เมื่อเข้าสู่ระบบ
- ความคืบหน้า โน้ต และผลฝึกสอบซิงก์แยกบัญชี มี revision check กันการเขียนทับจากอีกเครื่อง
- ค้นเนื้อหา ปรับตัวอักษร และอ่านต่อจากบทล่าสุด
- แผน C ครบ 84 หน่วยกิตใน 6 ภาค ภาคแรกลงจริง 21 นก. ภาคอนาคตย้ายได้และตรวจเพดานวางแผน
- วันสอบจากภาพลงทะเบียนจริง 10–22 มี.ค. 2570 พร้อมส่งออก `.ics` แบบทั้งวัน ไม่เดาชั่วโมงสอบ
- ติดตามเกรดและผลเทียบโอนที่ผู้เรียนกรอกเอง; ไม่ถือว่าหน่วยกิตคาดการณ์อนุมัติแล้ว
- สำรอง/นำเข้าความคืบหน้า JSON และส่งออก/นำเข้าสมุดจดพร้อมรูป JSON, พิมพ์โน้ต/PDF และแผน CSV

## ขอบเขตเนื้อหา

ชุดนี้เป็น **บทเรียนปูพื้นฐาน ไม่ใช่ตำราเต็มหรือคำบรรยายทางการ** และยังไม่ได้ตรวจความครอบคลุมกับแผนการสอนของอาจารย์ภาค 2/2569 ทุกคน ไม่อ้างว่าเป็นข้อสอบจริงหรือแนวที่จะออกสอบ ควรเรียนคู่ตำราและ RU Course on Demand และเพิ่มบันทึกจากอาจารย์

แนวคิดในบทเรียนเขียนใหม่จากความรู้พื้นฐานทางรัฐศาสตร์และการบริหาร ตัวอย่างเป็นกรณีสมมติ ไม่มีการคัดลอกตำรา/ถอดวิดีโอ แหล่งมหาวิทยาลัยในแอปใช้ยืนยันโครงสร้างและเป็นทางไปเรียนต่อ ไม่อ้างว่ามหาวิทยาลัยรับรองบทเรียนของแอป

## เปิดใช้งาน / พัฒนาต่อ

เป็น static app ใช้ Quill 2.0.3 และ Supabase JS 2.117.3 แบบตรึงรุ่นและเก็บไฟล์ browser ไว้ใน dist/vendor เนื้อหาเชื่อมกับโปรเจ็กต์ Supabase RU-Study-Planner แล้ว ข้อมูลสำรอง JSON ใช้เมื่อ API ขัดข้อง

```sh
python3 -m http.server 8080 --directory dist
# เปิด http://localhost:8080

npm run check
npm test
```

โฮสต์โฟลเดอร์ `dist/` บน static host ใดก็ได้ การนำทางใช้ hash จึงไม่ต้องตั้ง fallback routing

เมื่อ push เข้า `main` GitHub Actions จะตรวจ syntax และรันชุดทดสอบก่อนเผยแพร่เฉพาะ `dist/` ไปยัง GitHub Pages ไม่จำเป็นต้องติดตั้ง dependencies ส่วน pull request จะทดสอบอย่างเดียว

ไฟล์แอปเดิมถูกแทนที่ในรุ่นปัจจุบัน ประวัติ Git ยังคงอยู่ หากต้องการกู้เวอร์ชันก่อนเปลี่ยนโปรเจกต์ ให้ดู commit `9eb3b9d1e93825077333cecb583620834acacfc8`

### ไฟล์สำคัญ

- `dist/content.snapshot.json` — ข้อมูล 28 วิชา แผนทุกภาค บทเรียน 35 บท ข้อสอบฝึก 173 ข้อ และตารางเรียน
- `dist/content-client.js` — อ่าน Supabase ตรวจความครบถ้วน และเลือกสำเนาสำรองเมื่อ API ขัดข้อง
- `dist/supabase-config.js` — URL และ publishable key ของโปรเจ็กต์เรียน (ใช้ publishable key ซึ่งเปิดเผยในเบราว์เซอร์ได้)
- `dist/data.js`, `dist/lessons.js`, `dist/prep.js`, `dist/easy.js` — ส่งต่อข้อมูลที่โหลดแล้ว ไม่เก็บเนื้อหาก้อนใหญ่ใน JavaScript
- `dist/core.js` — คำนวณหน่วยกิต ตรวจข้อมูลสำรอง รอบทบทวน และแผนรายวัน
- `dist/calendar-core.js` — เกิดรอบบรรยายจากวันประจำสัปดาห์ ตรวจเวลาชน และส่งออก ICS
- `dist/calendar-view.js` — ปฏิทินรายเดือน/รายการ ตัวกรองรายวิชา และอ้างอิงที่เปิดได้
- `dist/resources-view.js` — ศูนย์เรียนออนไลน์และทางลัดไปตำรากับข้อสอบฝึก
- `dist/sources/mr30-2-2569-p142-143.pdf` — สำเนาสองหน้าจาก ม.ร.30 ของมหาวิทยาลัย ใช้เมื่อเว็บต้นฉบับขัดข้อง
- `database/schema.sql`, `database/seed.sql` — โครงสร้างและข้อมูลที่ย้ายแล้วเมื่อ 14 ต.ค. 2569 ไม่ต้องรัน schema ซ้ำ
- `docs/supabase-setup.md` — ขั้นตอนเชื่อมและแก้เนื้อหาผ่าน Table Editor

### การแก้เนื้อหา

หากอัปเดตสำเนาสำรอง แก้ `content.snapshot.json` โดยรักษา ID บทเดิม เช่น `POL1101-1` เพื่อไม่ตัดความคืบหน้าเดิม
หากเพิ่ม/ลบจำนวนรายการ ให้แก้ `counts` ให้ตรง และวันที่ `updated` จากนั้นรัน `npm run prepare:seed` กับชุดทดสอบ
แก้ตารางผ่าน Table Editor แล้วโหลดแอปใหม่ได้ โดยไม่แก้ HTML/JavaScript
ตัวเลือกคำถามใช้เลขคำตอบเริ่มที่ 0 และทุกคำถามต้องมีคำอธิบาย

### ความเป็นส่วนตัวและข้อจำกัด

- บันทึกและผลการเรียนอยู่ใน `localStorage` ของเบราว์เซอร์ ไม่ได้ส่งเข้า GitHub หรือ server
- ยังไม่มีการซิงก์หลายเครื่อง ให้ส่งออก JSON ก่อนย้ายเครื่องหรือล้างข้อมูล
- ไม่ใช่ระบบมหาวิทยาลัย ไม่ดึงผลสอบจริงและไม่ลงทะเบียนแทน
- GPA จำลองจากเกรดล่าสุดที่กรอก ไม่จำลองระเบียบการแทนเกรด/สอบซ้ำ
- ความหนักของรายวิชาเป็นการประเมินเพื่อกระจายภาระ ไม่ใช่ข้อมูลสถิติสอบผ่าน
- หากผลเทียบโอนไม่ใช่ 42 นก. ต้องปรับแผนเพิ่มเติม ไม่ถือว่าจบได้จากแผนนี้โดยอัตโนมัติ
- ชุดทดสอบอัตโนมัติตรวจตรรกะและข้อมูล รุ่น 11 ต.ค. 2569 ตรวจหน้าจอมือถือ/คอมพิวเตอร์และการกดใช้งานหลักด้วย Chromium แบบ manual แล้ว แต่ยังไม่มีชุดทดสอบ browser อัตโนมัติ
- แผนอ่านรายวันเป็นคำแนะนำ แยกจากปฏิทินบรรยายจริงตาม ม.ร.30; ไม่มีข้อมูลยืนยันว่าวิดีโอของแต่ละวิชาจะเปิดวันใด
- ปฏิทินเรียนอิงรอบประจำสัปดาห์ มีคำเตือนวันหยุด/งด/ชดเชย และไม่ใช้ห้องเรียนแทนห้องสอบ

## ปฏิทินและศูนย์เรียน รุ่น 14 ต.ค. 2569

- เปิด `#calendar` เพื่อดูวันเรียนและวันสอบ สลับรายเดือน/รายการ กรองวิชา และดาวน์โหลดทั้งเทอมเป็น ICS
- วันเรียนจาก ม.ร.30 หน้า 142–143 และช่วงบรรยายจาก CalendarCenter: 16 พ.ย. 2569–5 มี.ค. 2570
- POL2104 และ POL2106 เรียนพุธ 13:30–15:20 ตรงกัน; วันสอบของทั้ง 7 วิชาไม่ชนกัน
- งดบรรยาย 20 ม.ค. 2570 ตามปฏิทินทางการ; ช่วงสอบซ่อม 21–26 ม.ค. แสดงข้อความให้ตรวจประกาศ ไม่เดาว่างดทุกวัน
- เปิด `#resources` เพื่อเข้า RU on Demand ร้านหนังสือมหาวิทยาลัย บทเรียน และแบบฝึกของแต่ละวิชา
- ผ่าน 44 automated tests รวมการอ่านข้อมูลสำรอง การคงความคืบหน้าเดิม และปฏิทินเวลาไทย
- รุ่นนี้ยังไม่ได้ตรวจหน้าจอจริงด้วย browser; การตรวจ render เป็น integration test ด้วย minimal DOM host
- ผู้ใช้เปลี่ยนชื่อ repository เองเป็น RU-Study-Planner; localStorage อยู่ใน origin เดิมและใช้ key เดิม


## สมุดจดและ Supabase รุ่น 1.2.0

- เนื้อหาถูกย้ายเข้า `yikfrloyijdbwglswcww` แล้ว และตรวจ API จริง: 28 วิชา, 35 บท, 173 ข้อฝึก, 7 ตารางสอน
- `#notes` สมุดจด, `#note/<id>` ตัวแก้ไข, `#account` บัญชีและสถานะซิงก์

- `database/verify-access.sql` ทดสอบ owner/cross-user/anonymous/revision conflict แล้ว rollback ข้อมูลทดสอบทั้งหมด ผ่านบน Postgres จริง; security advisors ไม่พบรายการเตือน
- ยังต้องเปิด Google Provider และตั้ง Auth URL ใน Supabase ก่อนใช้งาน Google Login ขณะนี้ provider เป็น false ไม่อ้างว่าทดสอบการล็อกอินของผู้ใช้จริงแล้ว
- บันทึกเดิม `ru-study-planner.v1` เก็บไว้ สามารถคัดลอกข้อความเดิมเข้าสมุดจด และหลังลงชื่อสามารถเลือกคัดลอกข้อมูล guest เข้าบัญชี
- บันทึกไฟล์สำรองจากหน้า “สมุดจด” เพื่อรวมรูป; สำรองจาก “ตั้งค่า” เป็น progress/plain notes เท่านั้น
- ยังไม่ได้ตรวจ layout/การเลือกข้อความ/การวางรูปใน browser จริงในรุ่นนี้ ตรวจด้วย syntax, unit, render/event integration และ API/SQL เท่านั้น
- `vercel.json` เตรียม build/test และ output `dist` สำหรับโปรเจ็กต์ `study-plan` GitHub status ยืนยันว่า project นี้เชื่อม repository ถูกตัวแล้ว แต่ direct Vercel connector ตอบ 403 จึงติดตามผล deploy ผ่าน GitHub integration
- หากย้ายจาก GitHub Pages ไป Vercel ข้อมูล localStorage/IndexedDB จะไม่ย้ายข้าม origin อัตโนมัติ ให้ส่งออกสมุดจดพร้อมรูปและนำเข้าเว็บใหม่ หรือซิงก์ด้วยบัญชีเดิมหลังตั้ง Auth สำเร็จ
